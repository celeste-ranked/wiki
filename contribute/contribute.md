# Contribute

This wiki is open. If something is wrong, missing, or badly explained, you can fix it yourself.

Every page has an **Edit this page on GitHub** link at the bottom. Click it, make your changes and open a pr.

# Edit the Page

If you don't know how to use github, follow these steps:

1. Click on edit this page at the bottom and make sure you have a github account.

2. If it's your first time editing the page, make a fork of the repository.

3. Make the changes you want, and click preview on the top left to see how the markdown will look rendered. Use [this](https://vitepress.dev/guide/markdown) as a guide for all the formatting options.

4. When you are done and everything looks good, click the "Commit changes..." on the top right and add a commit message and make sure its easy to understand the change (pls don't use copilot for this). And then click propose changes.

5. Click "Create Pull Request", give it a title (and optional description) and click the create button again and thats it! Reviewers will review it and let you if any changes are needed or if its good before its deployed.
